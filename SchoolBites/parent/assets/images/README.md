# Asset organization

This folder keeps shared project assets grouped by purpose so the site stays easy to maintain without changing any page behavior.

Structure:
- brand/ — logos and brand artwork
- hero/ — promotional and hero section imagery
- meals/ — daily meal and food photography
- team/ — teammate and testimonial avatars
- use-cases/ — stakeholder and scenario imagery
- cta/ — call-to-action visuals

The existing production pages continue to reference the original asset locations until the team is ready for a full migration pass.
